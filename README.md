🏭 Featured Project

S.V.I. 4.0 — Intelligent Industrial Monitoring System

S.V.I. 4.0 is an industrial monitoring project created to collect, organize and display machine and sensor data.

The system connects software and hardware to help operators monitor equipment conditions, visualize historical information, identify abnormal behavior and support preventive maintenance decisions.

Main concepts and technologies:

ESP32, Arduino and industrial sensors

Temperature, vibration, current and production monitoring

Python, serial communication and API integration

Backend services and database organization

Dashboard interface and alert system

Preventive maintenance and Industry 4.0 concepts

AI-assisted analysis of machine behavior
