🏭 Projeto em destaque

S.V.I. 4.0 — Sistema de Vigilância Inteligente

O S.V.I. 4.0 é um projeto de monitoramento industrial desenvolvido para coletar, organizar e apresentar dados de máquinas e sensores.

A proposta é auxiliar operadores e equipes técnicas no acompanhamento das condições dos equipamentos, na identificação de comportamentos anormais e na tomada de decisões preventivas antes que ocorram falhas ou paradas na produção.

O protótipo disponível no GitHub realiza a integração entre Arduino e Python, com leitura de temperatura por sensor, comunicação serial, interface gráfica em tempo real e disponibilização dos dados por API.

Principais conceitos e tecnologias:

Integração entre hardware e software.

Leitura de sensores por Arduino.

Comunicação serial com Python.

Interface gráfica utilizando Tkinter.

API desenvolvida com Flask.

Monitoramento e exibição de dados em tempo real.

Simulação de dados quando o hardware não está conectado.

Conceitos de automação, IoT e Indústria 4.0.
